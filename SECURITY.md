# Security Policy

## Supported Versions

Security updates are provided on a best-effort basis for the latest release only. Older versions may not receive security updates.

| Version        | Supported          |
| -------------- | ------------------ |
| Latest release | :white_check_mark: |
| Older versions | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in HomeMascotForge, please report it through [GitHub's private vulnerability reporting](../../security/advisories/new), if available, or by email to the maintainer.

Please do not disclose unpatched vulnerabilities publicly.

Reports will be reviewed on a best-effort basis. There is no guaranteed response or resolution timeframe, and security fixes are not guaranteed.

This project is provided under the MIT License. Security reports are welcome, but the maintainer does not guarantee ongoing security support or maintenance.
